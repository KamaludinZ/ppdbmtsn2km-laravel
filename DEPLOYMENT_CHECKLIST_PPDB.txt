COMMANDS DI PRODUCTION:
-----------------------
1. Install dependencies (jika vendor belum di-upload):
   composer install --optimize-autoloader --no-dev

2. Setup environment:
   mv .env.production .env
   php artisan key:generate

3. Setup database:
   php artisan migrate --force
   php artisan db:seed --force

4. Create storage link:
   php artisan storage:link

5. Set permissions:
   chmod -R 775 storage/
   chmod -R 775 bootstrap/cache/

6. Clear & optimize:
   php artisan config:cache
   php artisan route:cache
   php artisan view:cache
   php artisan optimize

7. Test aplikasi:
   php artisan --version
   curl https://pmbm.mtsn2kotamalang.sch.id/

TROUBLESHOOTING:
----------------
Problem: Vite manifest not found
Solution: Pastikan folder public/build/ ter-upload dengan lengkap

Problem: Style berantakan
Solution: Clear browser cache & pastikan CSS ter-load

Problem: 500 Internal Server Error
Solution: Check storage/logs/laravel.log & set permissions

Problem: Database connection refused
Solution: Check .env credentials & PostgreSQL service
