TES PSIKOLOGI EXPORT SURVEY ANSWERS - ANALYSIS REPORT
=====================================================

ISSUE SUMMARY
=============
Export shows survey answer IDs (like "10") instead of labels (like "Pendek").
Both admin and panitia panels show labels correctly.

ROOT CAUSE
==========
1. Missing relationship: Export does not load ".options" in query
2. No conversion: Export uses raw jawaban value without conversion
3. Working code exists: SurveyAnswer model has getJawabanFormatted() helper

DATA STORAGE FORMAT
===================

Survey Answer Database Column: jawaban (TEXT/JSONB)

By Question Type:
- text/textarea: String (e.g., "Long text")
- radio: Single ID or VALUE (e.g., 10 or "pendek")
- select: Single ID or VALUE (e.g., 12 or "sedang")
- checkbox: JSON array (e.g., [10, 12, 15])

Two Data Approaches:
1. NEW (Feb 2026+): Store OPTION ID (e.g., 10)
   - Better data integrity
   - Admin can change label without breaking answers
   
2. OLD (before Feb 2026): Store OPTION VALUE (e.g., "pendek")
   - Backward compatibility

SURVEY QUESTION OPTIONS
=======================

SurveyQuestionOption fields:
- id: Option ID (primary key)
- survey_question_id: Foreign key
- label: Display text (e.g., "Pendek (150-160cm)")
- value: Alternative identifier (e.g., "pendek")
- urutan: Sort order

Example:
Question 5: "Berapa tinggi badanmu?"
├─ Option ID 10: label="Pendek", value="pendek"
├─ Option ID 11: label="Sedang", value="sedang"
└─ Option ID 12: label="Tinggi", value="tinggi"

EXPORT PROBLEMS
===============

Problem 1: Missing Relationship (Line 44)
Current:
  'pendaftar.surveyAnswers.question',
Missing:
  'pendaftar.surveyAnswers.question.options',

Without options, cannot convert ID to label.

Problem 2: No Conversion (Line 148-154)
Current:
  $jawaban = $answer->jawaban;  // Gets: 10
  if (is_array($jawaban)) {
    $baseData[] = implode(', ', $jawaban);  // Shows: "10, 12"
  } else {
    $baseData[] = $jawaban;  // Shows: "10"
  }

Should be:
  $baseData[] = $answer->getJawabanFormatted();  // Shows: "Pendek"

SOLUTION EXISTS
===============

SurveyAnswer Model: getJawabanFormatted()
- Lines 81-165 in SurveyAnswer.php
- Already implements complete solution
- Used in admin panel (WORKS)
- Used in panitia panel (WORKS)
- NOT used in export (BROKEN)

Conversion Logic:
1. Check question type
   - If text/textarea: return as-is
   - If radio/select/checkbox: convert to label

2. Try 4 matching methods (with priority):
   Method 1: Match by OPTION ID (numeric like "10")
   Method 2: Exact match by OPTION VALUE
   Method 3: Case-insensitive VALUE match
   Method 4: Case-insensitive LABEL match

3. Return label if found, or value with warning if not found
