TROUBLESHOOTING:
================

Error: "constraint already exists"
-----------------------------------
Migration sudah pernah di-run.
Check: php artisan migrate:status | grep "2026_02"
If "Ran" → skip, migration already applied

Error: "column already exists"
-------------------------------
Column sudah ada di database.
Check: \d daftar_ulang (via psql)
If exists → skip, migration already applied

Section Konfirmasi Tidak Muncul
--------------------------------
1. Check file uploaded: ls -la resources/views/livewire/pendaftar/daftar-ulang.blade.php
2. Clear cache: php artisan view:clear
3. Force recompile: rm -rf storage/framework/views/*

Excel Export Kolom Kosong
--------------------------
1. Clear cache: php artisan optimize:clear
2. Check file: ls -la app/Exports/DaftarUlangMadrasahSheet.php
3. Re-upload jika timestamp tidak hari ini
