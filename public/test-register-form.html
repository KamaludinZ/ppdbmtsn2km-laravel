Test Register Form

Test Checklist:

  1. Buka halaman /daftar
  2. Klik salah satu jalur pendaftaran
  3. Pastikan jalur yang diklik ter-highlight dengan warna dan tanda centang
  4. Pastikan tombol "Lanjutkan" berubah dari abu-abu ke hijau
  5. Klik tombol "Lanjutkan"
  6. Jika berhasil, Anda akan pindah ke Step 2 (Input Nilai)

Troubleshooting:

  • Jika tombol masih abu-abu setelah pilih jalur, refresh halaman (F5)
  • Buka Console browser (F12) dan lihat apakah ada error
  • Pastikan JavaScript tidak diblokir oleh browser
  • Clear browser cache (Ctrl+Shift+Delete)

Debug Info:

Untuk melihat debug info di browser console:

  1. Buka Console (F12)
  2. Saat klik jalur, akan muncul: "Selected Jalur ID: [nomor]"
  3. Cek tab Network untuk melihat request Livewire
