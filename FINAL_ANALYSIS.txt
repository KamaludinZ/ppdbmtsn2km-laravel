SURVEY DATA STORAGE
===================
Database: survey_answers.jawaban (TEXT/JSONB)

By Type:
- text: String "John"
- textarea: String "Long text"
- radio: ID (10) or VALUE ("pendek")
- select: ID (12) or VALUE ("sedang")
- checkbox: Array [10, 12, 15]

SURVEY OPTIONS STRUCTURE
=======================
Table: survey_question_options
Columns: id, survey_question_id, label, value, urutan

Example:
Question 5: "Tinggi badan?"
- Option 10: label="Pendek", value="pendek"
- Option 11: label="Sedang", value="sedang"
- Option 12: label="Tinggi", value="tinggi"

HOW IT WORKS NOW (BROKEN)
==========================
1. Export loads: 'pendaftar.surveyAnswers.question'
2. For each answer: $jawaban = $answer->jawaban
3. Shows: "10" (raw ID with no conversion)

HOW IT SHOULD WORK (FIXED)
===========================
1. Export loads: 'pendaftar.surveyAnswers.question.options'
2. For each answer: $answer->getJawabanFormatted()
3. Helper converts: 10 -> matches option 10 -> "Pendek"
4. Shows: "Pendek" (human readable label)

HELPER METHOD LOGIC
===================
getJawabanFormatted() process:

Input: jawaban = 10 (or "pendek" for old data)

Step 1: Check question type
- If text/textarea: return as-is
- If radio/select/checkbox: convert to label

Step 2: Try 4 matching methods
- Method 1: Match by OPTION ID (10 -> find option.id = 10)
- Method 2: Match by OPTION VALUE ("pendek" -> find option.value = "pendek")
- Method 3: Case-insensitive VALUE match
- Method 4: Case-insensitive LABEL match

Step 3: Return result
- If match found: return option->label ("Pendek")
- If not found: return raw value with warning ("10 ⚠️")
